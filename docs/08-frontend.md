# 08 - Frontend

## Objetivo

Aplicação React + TypeScript para administração e portal do morador.

## Telas planejadas

- Login
- Dashboard
- Condomínio
- Blocos
- Unidades
- Moradores
- Reservas
- Comunicados
- Ocorrências
- Financeiro
- Perfil

## Padrão de comunicação

O frontend deve usar um cliente HTTP único, guardar o token de forma segura para o contexto escolhido e enviar `Authorization: Bearer` para APIs privadas.

## Dashboard

Cards principais: blocos, unidades, moradores, ocorrências abertas, cobranças pendentes e reservas futuras.

## Evolução

A interface inicial existente é um protótipo funcional. A próxima etapa é transformar o protótipo em navegação por rotas, autenticação e páginas por domínio.
